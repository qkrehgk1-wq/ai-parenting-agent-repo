# Product Library

이 폴더는 실제 판매 가능한 상품 자산을 저장하는 공간이다.

## 구조

- `catalog/`
  상품 목록과 상태 관리
- `offers/`
  개별 상품 폴더

## 개별 상품 폴더 규칙

각 상품은 아래 파일 구성을 기본으로 한다.

- `meta.md`
  상품 개요, 타깃, 가격, 상태
- `content.md`
  실제 상품 본문 또는 원고
- `landing-copy.md`
  판매 페이지 문구
- `thumbnail-copy.md`
  썸네일/대표이미지 문구
- `delivery.md`
  구매 후 전달 방식과 구성

## 상태 예시

- `draft`
- `designing`
- `ready`
- `selling`
- `improving`
