# Design Team Architecture

## 목적

디자인 팀은 단순히 예쁘게 꾸미는 조직이 아니라, 상품의 이해도와 신뢰도, 전환율을 높이는 시각 운영팀이다.

## 팀 구성

### 1. Design Director Agent

- 전체 시각 방향 총괄
- 우선순위 결정
- 상품/랜딩/브랜드 간 일관성 검토

### 2. Product Design Agent

- PDF 상품과 디지털 자료의 레이아웃 담당
- 읽기 편한 구조와 강조 요소 설계

### 3. Landing Design Agent

- 판매 페이지와 신청 흐름 설계
- CTA와 신뢰 요소 배치

### 4. Brand Design Agent

- 색상, 폰트, 톤, 아이콘 분위기 정리
- 브랜드 일관성 유지

## 디자인 팀이 필요한 이유

- 좋은 정보도 보기 불편하면 구매 전환이 낮아진다
- 같은 내용이라도 시각 구조가 좋으면 신뢰도가 올라간다
- PDF, 랜딩, 뉴스레터, SNS 자산을 같은 브랜드 톤으로 묶을 수 있다

## 운영 원칙

- 디자인은 장식이 아니라 이해도와 전환을 위한 구조다
- 모바일 가독성을 우선한다
- 체크리스트, 루틴, 비교표는 시각 요소로 단순화한다
- 신뢰와 따뜻함이 동시에 느껴져야 한다

## 첫 적용 대상

1. 24개월 생활 루틴 가이드 PDF
2. PDF 판매 랜딩페이지
3. 뉴스레터 Plus 소개 페이지
