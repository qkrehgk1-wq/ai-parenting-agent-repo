# Upgrade Issue Comment Template

## 목적

이 템플릿은 `type:upgrade` 이슈에서 실험 진행 상황을 코멘트로 남길 때 사용하는 기준 형식이다.
업그레이드 팀이 무엇을 시도했고 무엇을 배웠는지 추적 가능하게 만드는 데 목적이 있다.

## 사용 시점

- 실험 시작 전
- 중간 결과 공유
- 실험 종료 후

## 코멘트 형식

### 실험 시작 코멘트

- 실험 목적:
- 이번에 바꾸는 범위:
- 건드리지 않는 범위:
- 성공 기준:
- 롤백 조건:

### 중간 점검 코멘트

- 현재까지 확인한 점:
- 예상보다 어려운 점:
- 추가 확인이 필요한 항목:
- 다음 액션:

### 종료 코멘트

- 실험 결과:
- 기대 효과 달성 여부:
- 실제 리스크:
- 운영 반영 추천 여부:
- 다음 PR 또는 이슈:

## 예시 종료 코멘트

- 실험 결과: PR 자동 요약 형식을 정의했고, 대표 에이전트가 PR 핵심을 더 빠르게 파악할 수 있는 구조를 마련함
- 기대 효과 달성 여부: 부분 달성
- 실제 리스크: 자동 요약 품질은 아직 PR 본문 품질에 영향을 받음
- 운영 반영 추천 여부: 예, 단 실제 PR 3건 이상으로 추가 검증 필요
- 다음 PR 또는 이슈: PR 요약 결과를 주간 리포트에 연결하는 후속 업그레이드 이슈 생성
