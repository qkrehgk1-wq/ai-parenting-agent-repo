# Kmong Go-To-Market

## 목적

AI 육아 상품을 크몽에서 실제로 판매하기 위한 플랫폼 맞춤 전략을 정리한다.

현재 크몽 진입의 핵심 타깃은 `4~7세 자녀를 둔 부모`다.

## 확인한 현재 플랫폼 성격

### 공식/준공식 확인

- 크몽은 전문가와 의뢰인을 연결하는 프리랜서 마켓으로 소개된다.
- 크몽 광고 상품 소개서(2024년 8월 버전)에서는 누적 거래 완료 500만 건+, 전체 의뢰인 만족도 98.6%를 강조한다.
- 기그 페이지 관찰상 전자책은 파일 형식의 디지털 콘텐츠로 판매 가능하다.
- 일부 전자책 기그에는 기본 전자책은 구매 관리에서 자동 발송, 심화/추가 전자책은 전문가 개별 발송으로 표시된다.

### 실제 기그 페이지 관찰로 본 공통 구조

- 제목
- 대표 썸네일
- 가격 패키지
- 서비스 설명
- 상세 이미지
- 서비스 제공 절차
- 취소/환불 조건
- 이용조건

즉, 단순 상품 소개보다 "무엇을 주는가 + 어떤 순서로 받는가 + 어디까지 해주는가"가 매우 중요하다.

## 육아 상품이 크몽에 맞는 이유

크몽에서 우리에게 맞는 건 크게 3가지다.

### 1. PDF/전자책형

- 루틴 가이드
- 체크리스트
- 놀이 자료집
- 부모 대화 예시집
- 예비초등 준비 자료집

장점:

- 자동 발송형 구조와 잘 맞는다
- 첫 구매 장벽이 낮다
- 후기와 리뷰를 쌓기 쉽다

### 2. 상담형

- 육아 루틴 점검
- 맞춤형 생활 구조 제안
- 부모 질문 기반 코칭
- 예비초등 생활습관 점검

장점:

- 고객당 단가를 올리기 쉽다
- PDF 구매자를 상담 상품으로 업셀하기 좋다

주의:

- 의료적 판단처럼 보이지 않도록 범위를 분명히 해야 한다

### 3. 맞춤 제작형

- 우리 집 루틴표 맞춤 제작
- 아이 성향 기반 놀이표 제작
- 부모용 일주일 루틴 리디자인
- 4~7세 생활습관표 맞춤 제작

장점:

- 차별화가 쉽다
- 재능마켓 성격과 잘 맞는다

## 우리가 먼저 제작해야 할 크몽용 상품

### Priority 1

- 4~5세 생활습관 루틴 가이드 PDF

이유:

- 4~7세 중심 전략과 맞다
- 습관/감정/일상 루틴 문제는 구매 이유가 분명하다
- 저가 첫 구매 상품으로 적합

### Priority 2

- 우리 집 맞춤 생활습관 점검 상담

이유:

- PDF 구매자 업셀 구조로 좋다
- 크몽의 상담형/서비스형 구조와 잘 맞는다

### Priority 3

- 6~7세 예비초등 생활 자료집 시리즈

이유:

- 전자책 라인업 확장 가능
- 리뷰 누적에 유리

## 추천 패키지 구조

### 옵션 A. 전자책 단일 상품

- BASIC: PDF 1종
- DELUXE: PDF + 체크리스트
- PREMIUM: PDF + 체크리스트 + 후속 Q&A 문서

### 옵션 B. 상담형 서비스

- BASIC: 1회 메시지 상담
- STANDARD: 1회 온라인 상담 + 요약 노트
- PREMIUM: 상담 + 맞춤 루틴표 정리

### 옵션 C. 혼합형

- PDF 구매
- 필요 시 상담 업셀
- 이후 맞춤 제작형으로 확장

## 크몽 상세페이지에서 꼭 보여줘야 할 것

1. 누구를 위한 상품인가
2. 어떤 문제를 덜 힘들게 해주는가
3. 구매 후 무엇을 받는가
4. 어떤 형식으로 전달되는가
5. 어디까지가 일반 정보이고 어디부터가 전문가 상담 영역인가

## 상세페이지 기획 구조

### Hero

- 문제 공감
- 상품 약속
- 가격
- 즉시 받을 수 있는 것

### Problem

- 부모가 겪는 반복 문제

### Inside

- PDF 또는 상담에 포함되는 것

### Process

- 구매 후 전달 방식
- 상담이면 일정 잡는 순서

### Trust

- 안전 문구
- 범위 안내
- 리뷰/기대효과

### CTA

- 지금 구매하기

## 제작 체크리스트

- 대표 썸네일
- 크몽 상세페이지용 긴 이미지
- 패키지 설명
- 서비스 제공 절차
- 전달 파일 형식 설명
- 환불/주의 문구
- 후기 유도 전략

## 우리 팀이 해야 할 일

- Kmong Planning Agent: 상품 구조 설계
- Product Design Agent: 상세페이지용 PDF/이미지 구성
- Landing Design Agent: 크몽 상세페이지 시각 흐름 적용
- Revenue Agent: 가격/패키지 설계
- Safety Agent: 표현 검수
- Learning Agent: 후기/전환 데이터 학습

## 현재 결론

크몽에서 가장 먼저 파는 건 `4~7세 저가 전자책형 상품 + 이후 상담 업셀` 구조가 가장 현실적이다.
