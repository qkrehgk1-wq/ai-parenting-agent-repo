# Kmong Product Blueprint

## 대상 상품

4~5세 생활습관 루틴 가이드 PDF

## 크몽용 제목 초안

- 4~5세 아이 생활습관 감정전환 루틴 PDF 가이드를 드립니다
- 4~5세 식사 정리 잠자리 습관 루틴 PDF 가이드를 드립니다
- 4~5세 부모를 위한 생활습관 실전 PDF 자료를 드립니다

## 추천 메인 제목 방향

`4~5세 아이 생활습관 감정전환 루틴 PDF 가이드를 드립니다`

이유:

- 연령 명확
- 고민 키워드가 분명함
- 전달물 형식이 명확함

## 대표 썸네일에 넣을 문구

- 4~5세 생활습관 루틴 가이드
- 식사 / 정리 / 감정 전환 / 잠자리
- 부모가 오늘 바로 적용하는 기준선

## 패키지 구조 초안

### BASIC

- PDF 1종 제공
- 가격 가설: 9,900원

### STANDARD

- PDF 1종
- 일주일 체크리스트 별도 1장
- 가격 가설: 14,900원

### PREMIUM

- PDF 1종
- 체크리스트
- 부모 대화 예시 보강본
- 가격 가설: 22,000원

## 상세페이지 핵심 카피

### 헤드라인

4~5세 아이와의 하루를 덜 힘들게 만드는 생활습관 루틴 가이드

### 서브 문구

식사, 정리, 감정 전환, 저녁 루틴까지.
검색으로 흩어진 정보를 모으는 대신 오늘 바로 적용할 수 있는 하루 흐름으로 정리했습니다.

### 포함 내용

- 아침/하원 후/저녁 루틴 예시
- 자주 무너지는 생활습관 포인트
- 부모 대화 예시
- 집에서 바로 하는 놀이와 전환 팁
- 일주일 체크리스트

### 전달 방식

- PDF 파일 제공
- 추가 자료가 있는 패키지는 별도 파일 동봉

## 구매 후 흐름

1. 구매 완료
2. PDF 다운로드 또는 전달
3. 체크리스트/추가 자료 제공
4. 필요 시 상담형 상품으로 업셀

## 주의 문구

- 본 자료는 일반적인 육아 정보와 실행 팁을 정리한 가이드입니다.
- 아이의 발달, 건강, 정서와 관련해 걱정되는 변화가 있다면 전문가 상담이 더 안전합니다.

## 후속 업셀 상품

- 우리 집 맞춤 생활습관 점검 상담
- 6~7세 예비초등 루틴 자료집
- AI 육아 코치 베타
