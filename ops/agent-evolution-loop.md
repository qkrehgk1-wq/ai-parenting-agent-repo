# Agent Evolution Loop

## 목적

에이전트들이 단순히 지시받은 일을 하는 수준을 넘어서, 스스로 일하고 스스로 진화하도록 운영 구조를 만든다.

## 핵심 루프

### 1. Observe

각 에이전트는 아래를 관찰한다.

- 어떤 작업이 오래 걸렸는가
- 어떤 결과물이 반응이 좋았는가
- 어떤 수정 요청이 반복됐는가
- 어떤 제안이 실제 매출로 이어졌는가

### 2. Diagnose

Learning Agent와 Upgrade Agent가 원인을 정리한다.

- 프롬프트 문제인가
- 모델 선택 문제인가
- 워크플로우 문제인가
- 상품 구조 문제인가

### 3. Experiment

작은 변경만 실험한다.

- 제목 구조 수정
- 상품 설명 방식 변경
- PR 요약 자동화 추가
- 배포 포맷 변경

### 4. Measure

분석 에이전트와 Revenue Agent가 본다.

- 시간 절감
- 전환율 변화
- 저장률
- 구독 증가
- 매출 변화

### 5. Institutionalize

잘된 실험은 운영 규칙으로 바꾼다.

- 프롬프트 수정
- 템플릿 업데이트
- 이슈 템플릿 개선
- 에이전트 역할 재정의

## 자가진화 조건

에이전트가 스스로 진화하려면 아래 4개가 있어야 한다.

1. 기억
   이전 실험과 교훈이 기록돼 있어야 한다

2. 측정
   좋아졌는지 나빠졌는지 숫자로 봐야 한다

3. 제한
   무엇을 자동으로 바꾸면 안 되는지 경계가 있어야 한다

4. 승인
   중요한 변화는 사람 승인 아래 반영해야 한다

## 추천 역할 분담

- Upgrade Agent: 무엇을 바꿔야 하는지 찾음
- Learning Agent: 무엇을 배웠는지 정리함
- Revenue Agent: 무엇이 돈이 되는지 판단함
- Chief Agent: 실제 반영 우선순위를 정함

## 한 줄 결론

진화는 "스스로 막 바꾸는 것"이 아니라 "관찰하고, 실험하고, 측정하고, 규칙으로 남기는 것"이다.
