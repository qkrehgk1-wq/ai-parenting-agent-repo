# GitHub Design References

## 목적

좋은 오픈소스 랜딩 레포에서 가져온 시각 원칙을 우리 상품 랜딩과 PDF에 적용하기 위한 메모다.

## 참고한 레퍼런스

### 1. shadcnstore/shadcn-dashboard-landing-template

참고 포인트:

- business-ready landing page 구조
- responsive, mobile-first 접근
- theme customization 중심 사고
- production-ready 느낌의 섹션 밀도

적용한 해석:

- 섹션별 목적을 분명히 나누기
- 카드형 콘텐츠와 CTA를 체계적으로 배치하기
- 브랜드 톤을 디자인 시스템으로 먼저 고정하기

### 2. leoMirandaa/shadcn-landing-page

참고 포인트:

- Hero, Stats, Features, CTA, FAQ 같은 전형적이지만 강한 랜딩 섹션 구조
- 빠르게 조립 가능한 마케팅 페이지 골격

적용한 해석:

- 상품 랜딩도 Hero → 문제 공감 → 포함 내용 → 추천 대상 → 가격/CTA 흐름으로 정리
- 읽는 흐름이 끊기지 않도록 섹션 단위를 명확히 분리

### 3. Finwise SaaS Landing Page

참고 포인트:

- lightweight, customizable 마케팅 랜딩
- modular하고 scalable한 구성
- 부드러운 전환과 정돈된 레이아웃 감각

적용한 해석:

- 과한 장식보다 가벼운 레이아웃과 여백 우선
- 판매 페이지도 빠르고 명확한 읽기 흐름 유지

## 우리 쪽 적용 원칙

1. Hero는 문제와 약속을 동시에 보여준다
2. CTA는 한 화면에 하나의 핵심 행동만 강조한다
3. 정보는 카드, 박스, 타임라인으로 나눠 인지 부담을 줄인다
4. PDF와 랜딩의 컬러/톤을 같은 시스템 아래 둔다
5. 귀엽기만 한 육아 톤이 아니라 따뜻하고 신뢰감 있는 톤으로 간다
