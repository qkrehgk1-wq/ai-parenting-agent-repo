# Design Planning Framework

## 목적

디자인 작업을 감각이나 즉흥성에 맡기지 않고, 분석과 기획 단계를 통해 더 일관되고 전환 중심으로 만들기 위한 기준 문서다.

## 디자인 기획이 필요한 이유

- 같은 상품이라도 어떤 순서로 보여주느냐에 따라 전환율이 달라진다
- 예쁜 시안과 팔리는 시안은 다를 수 있다
- 레퍼런스를 잘 모아도 해석 없이 쓰면 브랜드가 흔들린다

## 디자인 기획의 5단계

### 1. Goal

- 무엇을 팔려고 하는가
- 누구에게 보여주는가
- 어떤 행동을 유도할 것인가

### 2. Research

- GitHub 레퍼런스
- 유사 업종 랜딩 흐름
- 정보 구조 패턴
- 타깃 고객의 시각 기대치

### 3. Concept

- 핵심 키워드 3~5개
- 금지할 톤 2~3개
- 시각적으로 강조할 감정

### 4. Structure

- 섹션 순서
- 정보 우선순위
- CTA 위치
- 신뢰 요소 배치

### 5. Execution Brief

- Product Design Agent에게 넘길 레이아웃 지시
- Landing Design Agent에게 넘길 전환 구조 지시
- Brand Design Agent에게 넘길 톤/컬러 지시

## 디자인 기획 산출물

- 디자인 브리프 1장
- 레퍼런스 메모
- 컨셉 키워드
- 페이지 섹션 맵
- 체크리스트

## 우리 상품에 적용할 기본 질문

- 이 상품은 부모의 어떤 긴장을 낮춰주는가
- 이 화면에서 가장 먼저 보여야 할 것은 문제인가, 결과인가, 신뢰인가
- 정보가 너무 많아 보이지 않게 하려면 어디서 시각 분리가 필요한가
- 따뜻함과 전문성을 동시에 보이게 하려면 어떤 톤이 필요한가
