# Demo Issue 001

## 제목

[콘텐츠] 24개월 아이가 밥을 잘 안 먹을 때 부모가 오늘 바로 해볼 수 있는 방법

## 라벨

- `type:content`
- `source:demand`
- `status:research`
- `priority:high`

## 문제 상황

24개월 전후 아이가 밥 먹는 속도가 매우 느리거나, 특정 음식만 먹거나, 식사 시간마다 자리를 뜨려고 해서 부모가 지치고 불안해하는 상황이다.

## 타깃 부모

18개월~36개월 아이를 둔 부모

특히 아래에 해당하는 가정을 우선 대상으로 한다.

- 초보 부모
- 맞벌이 가정
- 저녁 식사 시간이 매일 전쟁처럼 느껴지는 부모

## 아이 연령

24개월

## 카테고리

식사

- 블로그 글
- 카드뉴스 문안
- 뉴스레터 요약
- 쇼츠 스크립트

## 민감도

주의

## 리서치 필요 범위

- 유아기 식습관 형성
- 편식과 식사 거부의 일반적 원인
- 부모 반응이 식사 행동에 미치는 영향
- 전문가 상담이 필요한 경고 신호

## 완료 기준

- 근거 자료 3개 이상 반영
- 안전 검수 통과
- 채널별 배포문 생성 완료

## Chief Agent 메모

이 주제는 검색 수요가 높고 반복 고민이 많다.
의료적 진단 대신 일반적인 생활 습관, 식사 환경, 부모 반응 중심의 해결안을 제공해야 한다.
